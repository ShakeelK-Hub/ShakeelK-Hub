## Selected work

### AI Anti-Sleep Glasses

<p align="center">
  <img
    width="94%"
    src="https://raw.githubusercontent.com/ShakeelK-Hub/ShakeelK-Hub/main/assets/system-map.gif"
    alt="AI Anti-Sleep Glasses system"
  />
</p>

A real-time driver-drowsiness detection system using a **CNN–LSTM pipeline** to classify eye-blink patterns.

The system was designed around embedded constraints, with the model optimised for **ESP32 deployment** and connected to Bluetooth alerting for fatigue notifications.

`Python` `CNN` `LSTM` `TensorFlow` `ESP32` `Bluetooth`

---

### Shopify Performance & Automation

At **DENM Digital**, I worked on a high-traffic Shopify platform where performance and operational efficiency were central to the work.

My contribution included front-end optimisation, Core Web Vitals improvements, asset optimisation, release automation and Shopify API workflows.

The automation layer processed **200+ product assets** and reduced repetitive operational work through **n8n and Make**.

`Shopify` `Liquid` `JavaScript` `n8n` `Make` `Shopify Admin API`

---

### Reusable Shopify Delivery

I built an optometry e-commerce solution around a reusable Shopify foundation rather than treating the project as a single deployment.

The system included React and Node.js components, automated catalogue creation through Shopify's Admin API, collection management and local SEO.

The architecture was designed around a repeatable delivery model capable of supporting **100+ potential client sites**.

`React` `Node.js` `REST APIs` `Shopify` `SEO`
